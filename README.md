# Project Widget

## Описание
Виджет, который показывает несколько последних успешных банковских операций клиента.

## Установка:
1. Клонируйте репозиторий:
```
git clone https://github.com/sunnymockingbird/project1.git
```
2. Установите зависимости:
```
pip install -r requirements.txt
```

## Использование функций:
### модуль masks:
Содержит функции:
* ***get_mask_card_number***:
<br>Принимает на вход номер банковской карты и маскирует его  в вид ХХХХ ХХ** **** ХХХХ
<br>Пример:
<br>Входной аргумент:7000792289606361
<br>Результат функции: 7000 79** **** 6361


* ***get_mask_account***:
<br>Принимает на вход номер счета и маскирует его в вид **ХХХХ
<br>Пример:
<br>Входной аргумент: 73654108430135874305
<br>Результат функции:**4305

### модуль widget:
Содержит функции:
* ***mask_account_card***:
<br>Обрабатывет информацию о картах и счетах и возвращает маску
<br>Примеры:
    * Входной аргумент: Visa Platinum 7000792289606361
  <br>Результат функции: Visa Platinum 7000 79** **** 6361
    * Входной аргумент: Счет 73654108430135874305
  <br>Результат функции: Счет **4305


* ***get_date***:
<br> Принимает на вход строку в ISO-формате и возвращает в формате "ДД.ММ.ГГГГ"
<br>Пример:
<br>Входной аргумент: "2024-03-11T02:26:18.671407"
<br>Результат функции: "ДД.ММ.ГГГГ"

### модуль processing:
Содержит функции:
* ***filter_by_state***:
<br>Принимает на вход список словарей и параметр state и отбирает только те, которые соответствуют заданному параметру


* ***sort_by_date***:
<br>Принимает на вход список словарей и сортирует их по ключу date (по дате)
<br> Если словарь не содержит ключа date, он помещается в конец списка словарей


### модуль generators:
Содержит функции:
* ***looking_name_of_currency***:
<br> Рекурсивно ищет в словаре ключ 'currency'(валюта) и возвращает наименование валюты
* ***filter_by_currency***
<br> Фильтрует список словарей по определенной валюте. Возвращает итератор.
* ***transaction_descriptions***
<br> Принимает список словарей транзакций и поочередно возвращает их описания. Возвращает генератор.
* ***card_number_generator***
<br> Генерирует номера карт в заданном диапазоне. Возвращает генератор.

## Тестирование
В проекте настроено автоматическое тестирование и проверка качества кода.
### Запуск тестов
Для запуска тестов используется фреймворк `pytest`. Чтобы запустить тесты в виртуальном окружении Poetry, выполните:
```
poetry run pytest
```

### Покрытие тестами (Code Coverage)
Для замера покрытия кода тестами используется утилита `pytest-cov`. 
* Чтобы запустить тесты с выводом общей таблицы покрытия в терминал:
```commandline
poetry run pytest --cov
```
