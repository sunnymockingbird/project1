# Project Widget

## Описание
Виджет, который показывает несколько последних успешных банковских операций клиента.

## Установка:
1. Клонируйте репозиторий:
```
git clone https://github.com/sunnymockingbird/project1.git
```
2. Установите зависимости:
```
pip install -r requirements.txt
```

## Использование функций:
### модуль masks:
Содержит функции:
* ***get_mask_card_number***:
<br>Принимает на вход номер банковской карты и маскирует его  в вид ХХХХ ХХ** **** ХХХХ
<br>Пример:
<br>Входной аргумент:7000792289606361
<br>Результат функции: 7000 79** **** 6361


* ***get_mask_account***:
<br>Принимает на вход номер счета и маскирует его в вид **ХХХХ
<br>Пример:
<br>Входной аргумент: 73654108430135874305
<br>Результат функции:**4305

### модуль widget:
Содержит функции:
* ***mask_account_card***:
<br>Обрабатывает информацию о картах и счетах и возвращает маску
<br>Примеры:
    * Входной аргумент: Visa Platinum 7000792289606361
  <br>Результат функции: Visa Platinum 7000 79** **** 6361
    * Входной аргумент: Счет 73654108430135874305
  <br>Результат функции: Счет **4305


* ***get_date***:
<br>Принимает на вход строку в ISO-формате и возвращает в формате "ДД.ММ.ГГГГ"
<br>Пример:
<br>Входной аргумент: "2024-03-11T02:26:18.671407"
<br>Результат функции: "ДД.ММ.ГГГГ"

### модуль processing:
Содержит функции:
* ***filter_by_state***:
<br>Принимает на вход список словарей и параметр state и отбирает только те, которые соответствуют заданному параметру
* ***sort_by_date***:
<br>Принимает на вход список словарей и сортирует их по ключу date (по дате)
<br>Если словарь не содержит ключа date, он помещается в конец списка словарей
* ***process_bank_search***:
<br>Ищет подстроку в описании транзакций без учёта регистра. Возвращает список словарей, содержащих совпадение.
* ***process_bank_operations***:
<br>Подсчитывает количество операций по заданным категориям. Возвращает Counter с количеством операций для каждой категории.

### модуль generators:
Содержит функции:
* ***looking_target_key***:
<br>Рекурсивно ищет в словаре ключ и возвращает его значение.
* ***get_currency_code***:
<br>Рекурсивно ищет в словаре ключ 'currency'(валюта) и возвращает код валюты.
* ***filter_by_currency***
<br>Фильтрует список словарей по определенной валюте. Возвращает итератор.
* ***transaction_descriptions***
<br>Принимает список словарей транзакций и поочередно возвращает их описания. Возвращает генератор.
* ***card_number_generator***
<br>Генерирует номера карт в заданном диапазоне. Возвращает генератор.

### модуль decorators:
Содержит декораторы:
* ***log***:
<br>При успешном выполнении записывает дату и время вызова, имя функции и сообщение об успешном завершении.
<br>При возникновении исключения записывает имя функции, тип ошибки и переданные аргументы, после чего повторно вызывает исключение.
<br>Если указан filename в качестве параметра, сообщения записываются в файл. Если имя файла не указано, сообщения выводятся в консоль.

### модуль utils:
Содержит функцию:
* ***read_file***:
<br>Принимает путь к файлу и возвращает его содержимое. Если файл не найден или пустой - возвращает пустой список.
<br>Может обрабатывать форматы json, csv, xlsx. В случае если будет иной формат - вернет пустой список.

### модуль external_api:
Содержит функцию:
* ***convert***:
<br>Конвертирует сумму транзакции в рубли. Для валют, отличных от RUB, получает данные о конвертации через внешний API. 
Для рублёвых операций возвращает исходную сумму. При отсутствии суммы или кода валюты, а также при ошибке API вызывает 
ValueError.
<br>Принимает на вход словарь транзакции. 

### модуль main:
Содержит функции:
* ***start***:
<br>Приветствует пользователя и предлагает выбрать формат файла с транзакциями (JSON, CSV или XLSX).
* ***choose_status***:
<br>Запрашивает статус операций для первой фильтрации. Проверяет корректность введённого значения и приводит его к 
верхнему регистру.
* ***get_correct_answer***:
<br>Запрашивает ответ на вопрос в формате «да/нет» или предлагает выбрать направление сортировки. Проверяет введённый
ответ и возвращает соответствующее булево значение.
* ***clarify_selection***:
<br>Уточняет дополнительные параметры обработки: сортировку по дате и её направление, фильтрацию по рублёвым операциям и
поиск по слову в описании.
* ***first_filtration***:
<br>Считывает выбранный файл и выполняет первую фильтрацию транзакций по статусу. Возвращает отфильтрованный список и 
флаг успешного чтения данных.
* ***second_filtration***:
<br>Применяет дополнительные параметры фильтрации и сортировки к полученному списку транзакций.
* ***main***:
<br>Управляет последовательностью обработки транзакций, обрабатывает отсутствие данных и выводит итоговую выборку с 
датами, описаниями, замаскированными номерами счетов и карт, суммами и валютами.

## Тестирование
В проекте настроено автоматическое тестирование и проверка качества кода.
### Запуск тестов
Для запуска тестов используется фреймворк `pytest`. Чтобы запустить тесты в виртуальном окружении Poetry, выполните:
```
poetry run pytest
```

### Покрытие тестами (Code Coverage)
Для замера покрытия кода тестами используется утилита `pytest-cov`. 
* Чтобы запустить тесты с выводом общей таблицы покрытия в терминал:
```commandline
poetry run pytest --cov
```
